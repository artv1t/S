# 🚀 SOLANA SNIPER BOT - ПОЛНОЕ РУКОВОДСТВО

## 📋 ОБЗОР БОТА

**Solana Sniper Bot** - это высокопроизводительный торговый бот для автоматического обнаружения и торговли новыми токенами на блокчейне Solana. Бот способен обрабатывать **1000+ событий в секунду** с задержкой менее **50мс**.

### 🎯 ОСНОВНЫЕ ВОЗМОЖНОСТИ:
- ✅ **Реальное обнаружение токенов** через подписки на программы
- ✅ **Трехэтапная фильтрация** токенов (Jupiter, OnChain, DexScreener)
- ✅ **Автоматическая торговля** с Take Profit / Stop Loss / TTL
- ✅ **Paper Trading** для безопасного тестирования
- ✅ **Live Trading** для реальной торговли
- ✅ **Web Dashboard** с профессиональным интерфейсом
- ✅ **Управление кошельками** с шифрованием
- ✅ **Риск-менеджмент** и защита от потерь

## 🛠️ УСТАНОВКА И НАСТРОЙКА

### 1. Скачивание бота
```bash
git clone https://github.com/artv1t/S.git
cd S/project
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка окружения
```bash
# Скопируй пример конфигурации
cp .env.example .env

# Отредактируй .env файл с твоими настройками
nano .env
```

### 4. Сборка проекта
```bash
npm run build
```

## ⚙️ КОНФИГУРАЦИЯ (.env файл)

### 🔗 RPC ENDPOINTS (ОБЯЗАТЕЛЬНО)
```bash
# Минимум 3 RPC endpoint'а для надежности
RPC_ENDPOINT_1=https://api.mainnet-beta.solana.com
RPC_ENDPOINT_2=https://solana-api.projectserum.com
RPC_ENDPOINT_3=https://rpc.ankr.com/solana
RPC_ENDPOINT_4=https://solana.blockdaemon.com
```

### 💰 ТОРГОВЫЕ ПАРАМЕТРЫ
```bash
# Сумма SOL на одну сделку
QUOTE_AMOUNT=0.0001

# Take Profit в процентах (50% = продать при +50% прибыли)
TAKE_PROFIT=50

# Stop Loss в процентах (30% = продать при -30% убытке)
STOP_LOSS=30

# Время жизни позиции в минутах (автопродажа)
TTL_MINUTES=30

# Максимальное количество одновременных сделок
MAX_CONCURRENT_TRADES=25

# Максимальное количество позиций
MAX_POSITIONS=100
```

### 🛡️ БЕЗОПАСНОСТЬ
```bash
# Лимит дневных потерь (5% от баланса)
DAILY_LOSS_LIMIT=0.05

# Максимальная экспозиция (20% от баланса)
MAX_EXPOSURE=0.2

# Circuit Breaker - пауза после N ошибок подряд
CIRCUIT_BREAKER_MAX_FAILURES=10
```

### 🎮 РЕЖИМЫ РАБОТЫ
```bash
# Paper Mode (безопасное тестирование)
PAPER_MODE=true

# Live Mode (реальная торговля)
PAPER_MODE=false
```

## 💼 УПРАВЛЕНИЕ КОШЕЛЬКАМИ

### Создание нового кошелька
```bash
# Через API
curl -X POST http://localhost:3001/api/wallets/create \
  -H "Content-Type: application/json" \
  -d '{"name": "main_wallet"}'
```

### Импорт существующего кошелька
```bash
# Создай файл с приватным ключом
echo "ваш_приватный_ключ_base58" > ./wallets/main_wallet.key

# Установи правильные права доступа
chmod 600 ./wallets/main_wallet.key
```

### Проверка балансов
```bash
curl http://localhost:3001/api/wallets/balances
```

## 🎯 API КОМАНДЫ

### 🤖 Управление ботом
```bash
# Запуск бота
curl -X POST http://localhost:3001/api/bot/start

# Остановка бота
curl -X POST http://localhost:3001/api/bot/stop

# Перезапуск бота
curl -X POST http://localhost:3001/api/bot/restart

# Статус бота
curl http://localhost:3001/api/bot/status
```

### 🪙 Управление токенами
```bash
# Добавить токен для отслеживания
curl -X POST http://localhost:3001/api/bot/tokens/add \
  -H "Content-Type: application/json" \
  -d '{"mintAddress": "адрес_токена"}'

# Удалить токен
curl -X DELETE http://localhost:3001/api/bot/tokens/remove \
  -H "Content-Type: application/json" \
  -d '{"mintAddress": "адрес_токена"}'

# Список отслеживаемых токенов
curl http://localhost:3001/api/bot/tokens
```

### 📈 Управление позициями
```bash
# Все активные позиции
curl http://localhost:3001/api/positions

# Закрыть позицию
curl -X POST http://localhost:3001/api/positions/close \
  -H "Content-Type: application/json" \
  -d '{"positionId": "id_позиции"}'

# Обновить Take Profit / Stop Loss
curl -X PUT http://localhost:3001/api/positions/update \
  -H "Content-Type: application/json" \
  -d '{
    "positionId": "id_позиции",
    "takeProfit": 75,
    "stopLoss": 25
  }'
```

### 💱 Ручная торговля
```bash
# Купить токен
curl -X POST http://localhost:3001/api/trading/buy \
  -H "Content-Type: application/json" \
  -d '{
    "mintAddress": "адрес_токена",
    "amount": 0.001,
    "walletName": "main_wallet"
  }'

# Продать токен
curl -X POST http://localhost:3001/api/trading/sell \
  -H "Content-Type: application/json" \
  -d '{
    "mintAddress": "адрес_токена",
    "percentage": 100,
    "walletName": "main_wallet"
  }'
```

### 🛡️ Безопасность
```bash
# Emergency Stop - немедленная остановка всех операций
curl -X POST http://localhost:3001/api/safety/emergency-stop

# Активировать Circuit Breaker
curl -X POST http://localhost:3001/api/safety/circuit-breaker

# Проверить лимиты
curl http://localhost:3001/api/safety/limits
```

## 🔧 РЕЖИМЫ РАБОТЫ

### 📊 Paper Mode (Тестирование)
**Что делает:**
- Симулирует реальную торговлю без трат денег
- Использует реальные цены и данные рынка
- Учитывает slippage и комиссии
- Сохраняет статистику в базу данных

**Как использовать:**
```bash
# Установи в .env
PAPER_MODE=true

# Запусти бота
npm run start:paper

# Смотри результаты в dashboard
http://localhost:3000
```

### 💸 Live Mode (Реальная торговля)
**Что делает:**
- Выполняет реальные транзакции на блокчейне
- Тратит реальные SOL на покупки
- Получает реальную прибыль/убыток
- Требует настроенные кошельки с балансом

**Как использовать:**
```bash
# Убедись что кошельки настроены
ls ./wallets/

# Проверь баланс
curl http://localhost:3001/api/wallets/balances

# Установи в .env
PAPER_MODE=false

# Запусти бота
npm run start:live
```

## 🛡️ БЕЗОПАСНОСТЬ И РИСК-МЕНЕДЖМЕНТ

### 🚨 Circuit Breaker
Автоматически останавливает бота при:
- 10+ ошибок подряд
- Превышении дневного лимита потерь
- Критических ошибках RPC

### 💰 Лимиты потерь
```bash
# Дневной лимит потерь (5% от баланса)
DAILY_LOSS_LIMIT=0.05

# Максимальная экспозиция (20% от баланса)
MAX_EXPOSURE=0.2
```

### 🔐 Защита кошельков
- Приватные ключи хранятся в зашифрованном виде
- Права доступа к файлам 600 (только владелец)
- Backup система для восстановления

### ⏰ Автоматические защиты
- **Take Profit** - автопродажа при достижении прибыли
- **Stop Loss** - автопродажа при достижении убытка
- **TTL (Time To Live)** - автопродажа через заданное время
