# 🔍 РУКОВОДСТВО ПО НАСТРОЙКЕ ФИЛЬТРОВ БОТА

## 🎯 ОБЗОР СИСТЕМЫ ФИЛЬТРАЦИИ

Бот использует **трехэтапную систему фильтрации** для отбора качественных токенов перед торговлей. Каждый фильтр имеет свою специализацию и настраиваемые параметры.

### 🔄 ПОСЛЕДОВАТЕЛЬНОСТЬ ФИЛЬТРОВ:
1. **RouteGate Filter** - Проверка ликвидности через Jupiter/Raydium
2. **OnChain Filter** - Анализ безопасности токена на блокчейне  
3. **DexScreener Filter** - Проверка социальных сетей и метаданных

---

## 1️⃣ ROUTEGATE FILTER (ФИЛЬТР ЛИКВИДНОСТИ)

### 🎯 Назначение
Проверяет ликвидность токена через Jupiter API с fallback на Raydium для обеспечения возможности торговли.

### ⚙️ Основные параметры (.env)
```bash
# Jupiter API настройки
JUPITER_API_KEY=                    # API ключ (опционально для free tier)
JUPITER_RATE_LIMIT=5               # Запросов в секунду (5 для free, 50+ для paid)
JUPITER_TIMEOUT=10000              # Таймаут запроса в мс

# Raydium fallback
RAYDIUM_ENABLED=true               # Включить Raydium как fallback
RAYDIUM_RATE_LIMIT=2               # Запросов в секунду для Raydium

# Параметры фильтрации
ROUTE_GATE_MIN_LIQUIDITY=1000      # Минимальная ликвидность в USD
ROUTE_GATE_MAX_PRICE_IMPACT=10     # Максимальный price impact в %
ROUTE_GATE_MIN_SCORE=70            # Минимальный score для прохождения
```

### 🔧 Детальная настройка
```bash
# В файле src/filters/routeGateFilter.ts можно настроить:

# Scoring система
LIQUIDITY_WEIGHT=0.4               # Вес ликвидности в общем score
PRICE_IMPACT_WEIGHT=0.3            # Вес price impact в score  
ROUTE_QUALITY_WEIGHT=0.3           # Вес качества маршрута в score

# Кэширование
ROUTE_CACHE_TTL=60000              # Время жизни кэша в мс (1 минута)
ROUTE_CACHE_SIZE=5000              # Максимальный размер кэша

# Rate limiting
RATE_LIMIT_WINDOW=1000             # Окно rate limiting в мс
RATE_LIMIT_MAX_REQUESTS=5          # Максимум запросов в окне
```

### 📊 Логика scoring
```javascript
// Расчет score для токена
const liquidityScore = Math.min(liquidity / 10000, 1) * 40;  // 0-40 points
const impactScore = Math.max(0, (10 - priceImpact) / 10) * 30; // 0-30 points  
const routeScore = routeExists ? 30 : 0;                     // 0-30 points
const totalScore = liquidityScore + impactScore + routeScore; // 0-100 points

// Проходит если score >= 70
```

### 🛠️ Настройка через API
```bash

curl -X PUT http://localhost:3001/api/bot/filters/routegate \
  -H "Content-Type: application/json" \
  -d '{
    "minLiquidity": 2000,
    "maxPriceImpact": 8,
    "minScore": 75,
    "enabled": true
  }'

# Получить текущие настройки
curl http://localhost:3001/api/bot/filters/routegate | jq
```

## 2️⃣ ONCHAIN FILTER (ФИЛЬТР БЕЗОПАСНОСТИ)

### 🎯 Назначение
Анализирует токен на блокчейне для выявления потенциальных рисков и проблем безопасности.

### ⚙️ Основные параметры (.env)
```bash
# RPC настройки для OnChain анализа
HELIUS_API_KEY_1=your_helius_key_1  # Основной Helius RPC ключ
HELIUS_API_KEY_2=your_helius_key_2  # Резервный Helius RPC ключ
ONCHAIN_TIMEOUT=5000                # Таймаут RPC запросов в мс
ONCHAIN_RATE_LIMIT=10               # Запросов в секунду

# Параметры безопасности
ONCHAIN_MIN_SCORE=60                # Минимальный score для прохождения
CHECK_MINT_AUTHORITY=true           # Проверять mint authority
CHECK_FREEZE_AUTHORITY=true         # Проверять freeze authority
CHECK_HOLDER_CONCENTRATION=true     # Проверять концентрацию держателей
```

### 🔧 Детальные проверки
```bash
# Mint Authority проверки
REQUIRE_RENOUNCED_MINT=true         # Требовать renounced mint authority
ALLOW_MULTISIG_MINT=false           # Разрешить multisig mint authority

# Freeze Authority проверки  
REQUIRE_NO_FREEZE=true              # Требовать отсутствие freeze authority
ALLOW_MULTISIG_FREEZE=false         # Разрешить multisig freeze authority

# Supply проверки
MIN_TOTAL_SUPPLY=1000000            # Минимальный total supply
MAX_TOTAL_SUPPLY=1000000000000      # Максимальный total supply
MIN_DECIMALS=6                      # Минимальное количество decimals
MAX_DECIMALS=9                      # Максимальное количество decimals

# Концентрация держателей
MAX_TOP1_HOLDER_PERCENT=20          # Максимум у топ-1 держателя (%)
MAX_TOP5_HOLDER_PERCENT=50          # Максимум у топ-5 держателей (%)
MIN_HOLDER_COUNT=100                # Минимальное количество держателей
```

### 📊 Система scoring
```javascript
// Расчет безопасности токена
let score = 0;

// Mint authority (0-25 points)
if (mintAuthority === null) score += 25;
else if (isMultisig(mintAuthority)) score += 15;

// Freeze authority (0-25 points)  
if (freezeAuthority === null) score += 25;
else if (isMultisig(freezeAuthority)) score += 15;

// Supply и decimals (0-20 points)
if (supply >= MIN_SUPPLY && supply <= MAX_SUPPLY) score += 10;
if (decimals >= MIN_DECIMALS && decimals <= MAX_DECIMALS) score += 10;

// Концентрация держателей (0-30 points)
if (top1HolderPercent <= MAX_TOP1_HOLDER_PERCENT) score += 15;
if (top5HolderPercent <= MAX_TOP5_HOLDER_PERCENT) score += 15;

// Проходит если score >= 60
```

### 🛠️ Настройка через API
```bash

curl -X PUT http://localhost:3001/api/bot/filters/onchain \
  -H "Content-Type: application/json" \
  -d '{
    "minScore": 65,
    "checkMintAuthority": true,
    "checkFreezeAuthority": true,
    "maxTop1HolderPercent": 15,
    "enabled": true
  }'

# Получить статистику OnChain проверок
curl http://localhost:3001/api/bot/filters/onchain/stats | jq
```

## 3️⃣ DEXSCREENER FILTER (СОЦИАЛЬНЫЙ ФИЛЬТР)

### 🎯 Назначение
Проверяет социальные сети, веб-сайты и метаданные токена для оценки легитимности проекта.

### ⚙️ Основные параметры (.env)
```bash
# DexScreener API
DEXSCREENER_RATE_LIMIT=2            # Запросов в секунду (free tier)
DEXSCREENER_TIMEOUT=5000            # Таймаут запроса в мс
DEXSCREENER_MIN_SCORE=75            # Минимальный score для прохождения

# Социальные сети
REQUIRE_TWITTER=true                # Требовать Twitter
REQUIRE_TELEGRAM=false              # Требовать Telegram  
REQUIRE_WEBSITE=true                # Требовать веб-сайт
MIN_SOCIAL_COUNT=2                  # Минимум социальных сетей

# Метаданные
CHECK_TOKEN_AGE=true                # Проверять возраст токена
MIN_TOKEN_AGE_HOURS=1               # Минимальный возраст в часах
MAX_TOKEN_AGE_DAYS=30               # Максимальный возраст в днях
```

### 🔧 Детальные проверки
```bash
# Twitter проверки
TWITTER_MIN_FOLLOWERS=100           # Минимум подписчиков
TWITTER_CHECK_VERIFIED=false        # Проверять верификацию
TWITTER_CHECK_ACTIVITY=true         # Проверять активность

# Telegram проверки  
TELEGRAM_MIN_MEMBERS=50             # Минимум участников
TELEGRAM_CHECK_ADMIN_ACTIVITY=true  # Проверять активность админов

# Веб-сайт проверки
WEBSITE_CHECK_SSL=true              # Проверять SSL сертификат
WEBSITE_CHECK_CONTENT=true          # Проверять контент сайта
WEBSITE_TIMEOUT=10000               # Таймаут проверки сайта

# Листинги и пары
MIN_DEX_PAIRS=1                     # Минимум торговых пар
REQUIRE_MAJOR_DEX=false             # Требовать листинг на крупной DEX
CHECK_LIQUIDITY_LOCKED=true         # Проверять заблокированную ликвидность
```

### 📊 Система scoring
```javascript
// Расчет социального score
let score = 0;

// Социальные сети (0-40 points)
if (hasTwitter) score += 15;
if (hasTelegram) score += 10;  
if (hasWebsite) score += 15;

// Качество социальных сетей (0-30 points)
if (twitterFollowers >= MIN_FOLLOWERS) score += 10;
if (telegramMembers >= MIN_MEMBERS) score += 10;
if (websiteHasSSL && websiteHasContent) score += 10;

// Листинги и активность (0-30 points)
if (dexPairs >= MIN_DEX_PAIRS) score += 15;
if (liquidityLocked) score += 15;

// Проходит если score >= 75
```

## 🔍 СОЗДАНИЕ КАСТОМНЫХ ФИЛЬТРОВ

### Пример кастомного фильтра
```typescript
// src/filters/customFilter.ts
export class CustomFilter {
  async filter(token: TokenEvent): Promise<FilterResult> {
    let score = 0;
    const reasons: string[] = [];
    
    // Твоя логика фильтрации
    if (token.name.includes('MOON')) {
      score += 20;
    }
    
    if (token.symbol.length <= 5) {
      score += 10;
    } else {
      reasons.push('Symbol too long');
    }
    
    return {
      passed: score >= 50,
      score,
      reasons,
      metadata: { customCheck: true }
    };
  }
}
```

### Интеграция кастомного фильтра
```typescript
// src/filters/filterPipeline.ts
import { CustomFilter } from './customFilter.js';

// Добавь в pipeline
this.filters = [
  new RouteGateFilter(),
  new OnChainFilter(), 
  new DexScreenerFilter(),
  new CustomFilter()  // Твой фильтр
];
```

## 🚨 УСТРАНЕНИЕ ПРОБЛЕМ

### Фильтры не работают
```bash
# Проверь API ключи
echo $JUPITER_API_KEY
echo $HELIUS_API_KEY_1

# Проверь подключение к API
curl -s "https://quote-api.jup.ag/v6/quote?inputMint=So11111111111111111111111111111111111111112&outputMint=EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v&amount=1000000"

# Проверь логи фильтров
tail -f logs/filters.log
```

### Низкая пропускная способность
```bash
# Проверь rate limits
curl http://localhost:3001/api/bot/filters/rate-limits | jq

# Увеличь таймауты если много timeout ошибок
ROUTE_GATE_TIMEOUT=15000
```
