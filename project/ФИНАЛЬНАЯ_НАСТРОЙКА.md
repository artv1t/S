## 📋 ЧЕКЛИСТ ГОТОВНОСТИ

### ✅ ШАГ 1: ПРОВЕРКА СИСТЕМЫ
```bash
# Проверь версию Node.js (требуется 18+)
node --version

# Проверь npm
npm --version

# Перейди в директорию проекта
cd /path/to/S/project
```

### ✅ ШАГ 2: УСТАНОВКА ЗАВИСИМОСТЕЙ
```bash
# Установи все зависимости
npm install

# Проверь что нет ошибок TypeScript
npx tsc --noEmit

# Собери проект
npm run build
```

### ✅ ШАГ 3: НАСТРОЙКА ОКРУЖЕНИЯ
```bash
# Скопируй пример конфигурации
cp .env.example .env

# Отредактируй .env файл
nano .env
```

**Обязательные параметры в .env:**
```bash
# RPC ENDPOINTS (минимум 3)
RPC_ENDPOINT_1=https://api.mainnet-beta.solana.com
RPC_ENDPOINT_2=https://solana-api.projectserum.com  
RPC_ENDPOINT_3=https://rpc.ankr.com/solana
RPC_ENDPOINT_4=https://solana.blockdaemon.com

# ТОРГОВЫЕ ПАРАМЕТРЫ
QUOTE_AMOUNT=0.0001          # Сумма SOL на сделку
TAKE_PROFIT=50               # Take profit %
STOP_LOSS=30                 # Stop loss %
TTL_MINUTES=30               # Время жизни позиции

# РЕЖИМ РАБОТЫ
PAPER_MODE=true              # Начни с тестирования!

# БЕЗОПАСНОСТЬ
DAILY_LOSS_LIMIT=0.05        # 5% дневной лимит потерь
MAX_EXPOSURE=0.2             # 20% максимальная экспозиция
CIRCUIT_BREAKER_MAX_FAILURES=10
```

### ✅ ШАГ 4: СОЗДАНИЕ КОШЕЛЬКОВ

#### Вариант A: Создание нового кошелька
```bash
# Создай директорию для кошельков
mkdir -p ./wallets

# Запусти бота для создания кошелька через API
npm run start:paper &

# Подожди 10 секунд, затем создай кошелек
sleep 10
curl -X POST http://localhost:3001/api/wallets/create \
  -H "Content-Type: application/json" \
  -d '{"name": "main_wallet"}'

# Останови бота
pkill -f "npm run start:paper"
```

#### Вариант B: Импорт существующего кошелька
```bash
# Создай файл с приватным ключом (base58 формат)
echo "твой_приватный_ключ_base58" > ./wallets/main_wallet.key

# Установи правильные права доступа (КРИТИЧНО!)
chmod 600 ./wallets/main_wallet.key

# Проверь права
ls -la ./wallets/
# Должно быть: -rw------- main_wallet.key
```

## 📊 ОЖИДАЕМЫЕ РЕЗУЛЬТАТЫ

### 📈 Paper Mode (24 часа тестирования):
- **Обнаруженных токенов**: 100-500
- **Прошедших фильтры**: 5-20  
- **Симулированных сделок**: 3-15
- **Средний PnL**: зависит от рынка

### 💰 Live Mode (первый день):
- **Реальных сделок**: 1-5 (начни консервативно)
- **Использованный SOL**: 0.0005-0.005
- **Ожидаемый результат**: +10% до +50% (при удаче)
