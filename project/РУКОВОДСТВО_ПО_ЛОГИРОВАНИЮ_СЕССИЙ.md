# 📊 РУКОВОДСТВО ПО СИСТЕМЕ ЛОГИРОВАНИЯ СЕССИЙ

## 🎯 ОБЗОР СИСТЕМЫ

Система логирования сессий автоматически создает детальные отчеты о каждом запуске бота с полной информацией о торговых операциях, балансах и производительности.

### 🔥 КЛЮЧЕВЫЕ ОСОБЕННОСТИ:
- ✅ **Автоматическая нумерация** файлов (run_001.json, run_002.json, ...)
- ✅ **Полные торговые отчеты** с балансами на начало/конец
- ✅ **Статистика фильтров** и производительности
- ✅ **Автопродажа позиций** при остановке бота
- ✅ **Real-time мониторинг** через API endpoints

---

## 📁 СТРУКТУРА ФАЙЛОВ

### Расположение логов
```bash
/project/trading_logs/
├── run_001.json    # Первый запуск
├── run_002.json    # Второй запуск  
├── run_003.json    # Третий запуск
└── ...
```

### Автоматическая нумерация
- При первом запуске создается `run_001.json`
- При каждом новом запуске номер увеличивается автоматически
- Если папку `trading_logs/` очистить, нумерация начнется с `run_001.json`

## 📊 ОПИСАНИЕ ПОЛЕЙ ОТЧЕТА

### 🔢 Основная информация
- **sessionId**: Уникальный ID сессии
- **sessionNumber**: Порядковый номер запуска
- **startTime/endTime**: Время начала/окончания сессии
- **duration**: Продолжительность работы в миллисекундах

### 💰 Финансовые данные
- **startingBalance**: Баланс SOL на начало сессии
- **endingBalance**: Баланс SOL на конец сессии
- **totalPnL**: Общая прибыль/убыток в SOL
- **totalPnLPercent**: Процент прибыли/убытка

### 📈 Торговые операции (trades)
- **timestamp**: Время сделки
- **mintAddress**: Адрес токена
- **action**: Тип операции (BUY, SELL, TAKE_PROFIT, STOP_LOSS, AUTO_SELL)
- **amount**: Количество токенов
- **price**: Цена за токен
- **solAmount**: Сумма в SOL
- **txHash**: Хэш транзакции
- **reason**: Причина продажи (для SELL операций)

### 🔍 Статистика фильтров (filterStats)
- **tokensDiscovered**: Всего обнаружено токенов
- **tokensFiltered**: Токенов отфильтровано
- **routeGatePassed**: Прошли RouteGate фильтр
- **onChainPassed**: Прошли OnChain фильтр
- **dexScreenerPassed**: Прошли DexScreener фильтр
- **totalPassed**: Всего прошли все фильтры

### ⚡ Метрики производительности (performanceMetrics)
- **peakTokensPerSecond**: Пиковая скорость обработки
- **averageTokensPerSecond**: Средняя скорость обработки
- **memoryUsageMB**: Использование памяти в МБ
- **rpcLatencyMs**: Задержка RPC в миллисекундах
- **filterLatencyMs**: Задержка фильтров в миллисекундах

### 🎯 Торговая статистика
- **successfulTrades**: Успешные сделки
- **failedTrades**: Неудачные сделки
- **autoSellCount**: Количество автопродаж
- **positionsAtShutdown**: Позиции на момент остановки

## 🔄 АВТОПРОДАЖА ПОЗИЦИЙ

### Как работает
При остановке бота (Ctrl+C или API команда) система автоматически:

1. **Определяет активные позиции**
2. **Продает все открытые токены** по рыночной цене
3. **Логирует операции** как "AUTO_SELL"
4. **Обновляет финальный баланс**
5. **Финализирует отчет сессии**

### Пример автопродажи в логах
```json
{
  "timestamp": "2025-09-19T16:35:00.100Z",
  "mintAddress": "DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263",
  "action": "AUTO_SELL",
  "amount": 500000,
  "price": 0.000012,
  "solAmount": 0.006,
  "txHash": "9L2...ghi",
  "reason": "auto_sell"
}
```

### Отключение автопродажи
```bash
# В .env файле (НЕ РЕКОМЕНДУЕТСЯ)
AUTO_SELL_ON_SHUTDOWN=false
```

## 📊 АНАЛИЗ ОТЧЕТОВ

### Расчет прибыльности
```bash
# Скрипт для анализа всех сессий
cat trading_logs/run_*.json | jq '.totalPnL' | awk '{sum+=$1} END {print "Total PnL:", sum, "SOL"}'

# Средняя прибыль за сессию
cat trading_logs/run_*.json | jq '.totalPnL' | awk '{sum+=$1; count++} END {print "Average PnL:", sum/count, "SOL"}'
```

### Анализ успешности сделок
```bash
# Процент успешных сделок
cat trading_logs/run_*.json | jq '.successfulTrades, .failedTrades' | awk 'NR%2==1{s=$1} NR%2==0{f=$1; if(s+f>0) print "Success rate:", s/(s+f)*100"%"}'
```

### Производительность фильтров
```bash
# Эффективность фильтров
cat trading_logs/run_*.json | jq '.filterStats | .totalPassed / .tokensDiscovered * 100' | awk '{sum+=$1; count++} END {print "Average filter pass rate:", sum/count "%"}'
```

## 🛠️ УПРАВЛЕНИЕ ЛОГАМИ

### Очистка старых логов
```bash
# Удалить все логи (нумерация начнется с run_001.json)
rm -rf trading_logs/*

# Удалить логи старше 30 дней
find trading_logs/ -name "run_*.json" -mtime +30 -delete
```

### Архивирование логов
```bash
# Создать архив логов за месяц
tar -czf logs_$(date +%Y-%m).tar.gz trading_logs/

# Переместить в архив
mkdir -p archive/
mv logs_*.tar.gz archive/
```

### Ротация логов
```bash
# Оставить только последние 100 сессий
ls -t trading_logs/run_*.json | tail -n +101 | xargs rm -f
```

## 🔍 МОНИТОРИНГ В РЕАЛЬНОМ ВРЕМЕНИ

### WebSocket подключение
```javascript
// Подключение к real-time обновлениям
const ws = new WebSocket('ws://localhost:3001/ws');

ws.onmessage = function(event) {
  const data = JSON.parse(event.data);
  if (data.type === 'session_update') {
    console.log('Session update:', data.session);
  }
};
```

### Мониторинг через curl
```bash
# Мониторинг каждые 10 секунд
while true; do
  curl -s http://localhost:3001/api/bot/session/current | jq '.currentBalance, .activeTrades, .totalPnL'
  sleep 10
done
```
